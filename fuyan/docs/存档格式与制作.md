# 存档格式与制作指南（`fuyan/archive@1`）

> 一个存档 = 一门课的**内容** + **题库** + 元数据。软件本身不含任何课程内容。
> 现在的两份存档：`data/archives/infectious`（传染病学）、`data/archives/digestive`（消化系统）。

---

## 一、目录结构

```
<id>/
├─ manifest.json      # 必需：元数据、导航、题库统计
├─ content.html       # 必需：完整内容文档（自带样式）
├─ questions.json     # 可选：题库（没有就只阅读）
└─ assets/            # 可选：图片等（content 里用相对路径引用）
```

`<id>` 只能包含字母数字 `._-`，等于 `manifest.json` 里的 `id`。

---

## 二、manifest.json

```json
{
  "schema": "fuyan/archive@1",
  "id": "infectious",
  "title": "传染病学",
  "subtitle": "期末复习综合站",
  "version": "1.3.0",
  "builtAt": "2026-11-14T12:44:41+0800",
  "accent": "#0f766e",
  "theme": { "bg": "#f6f5f1", "panel": "#fffefb", "ink": "#1d2430", "muted": "#6b7280" },
  "nav": [
    { "group": "大题（详细再复习）" },
    { "anchor": "naming", "title": "名词解释", "badge": "①", "sectionId": "sec-naming", "count": 22 }
  ],
  "quiz": { "total": 196, "topics": ["总论"], "tags": ["高频"], "types": ["single"] },
  "source": { "kind": "local", "file": "复习综合站.html" }
}
```

| 字段 | 说明 |
|---|---|
| `nav[]` | 侧栏导航。`{group}` 是分组标题；其余项要有 `title` + `sectionId`（对应 `content.html` 里的元素 id）。`badge` 是序号/图标，`count` 显示数量。 |
| `accent` | 主色，软件外壳会用它点缀（打开该存档时）。 |
| `quiz` | 只用于首页卡片统计；真正的题目在 `questions.json`。 |
| `source` | `local` 或 `quark`。从网盘导入时软件会自动写入 `quarkName / quarkSize / quarkUpdatedAt / quarkFid`，用于更新比对。 |

## 三、content.html

- 一个**完整的 HTML 文档**（`<!doctype html>` + `<style>` + 内容），软件用同源 iframe 加载。
- 唯一的硬要求：`nav[].sectionId` 指向的元素要在文档里存在（`id="..."`）。
- 软件会在服务端往 `<head>` 注入 `overlay.css`、往 `</body>` 前注入 `runtime.js`，所以：
  - **不要**在存档里写 `<script>`（会被忽略/清掉）；
  - 交互控件用 `data-act` 声明（见下），由软件实现行为。
- 原站外壳（侧栏、顶栏、弹窗、题库区）应该在制作时删掉，只留内容。

### 运行时认的 `data-act`

| 值 | 作用 | 额外属性 |
|---|---|---|
| `expand-all` / `collapse-all` | 展开/收起所有折叠问答 | `data-scope` 选择器 |
| `flip-mode` | 名解「只看英文」 | — |
| `shuffle` | 打乱卡片 | — |
| `tab` | 速查/标签页切换 | `data-qt` |
| `filter-flash` | 名解卡按模块筛选 | `data-filter`、`data-target` |
| `mastered` | 名解「标记已背」 | `data-key` |
| `module-mastered` | 模块「标记已掌握」 | `data-key` |
| `seg` | 对照表遮 A / 遮 B / 并列 | `data-mode`、`data-target` |

另外这些**类名**会被运行时接管：`.qa`（点 header 展开）、`.card`/`.flashcard`（点击翻转）、`details/summary`（原生）。

### 可选占位符（运行时填）

| id | 内容 |
|---|---|
| `#home-qn` | 题库总数 |
| `#home-progress` | 「已做 X / N · 正确 Y · 错误 Z」 |
| `#n-<anchor>` | 导航上的数量 |
| `#foot-n` | 总题数 |

## 四、questions.json

```json
{
  "schema": "fuyan/questions@1",
  "count": 196,
  "questions": [{
    "id": "A-001",
    "type": "single",
    "topic": "总论",
    "tags": ["病例题", "数字题"],
    "src": "自编·课件+课本",
    "stem": "男，28 岁……（　）",
    "stemEn": null,
    "options": [{ "zh": "弛张热", "en": null }],
    "answer": [3],
    "answerText": null,
    "explain": "选 D。……"
  }]
}
```

| 字段 | 说明 |
|---|---|
| `type` | `single` 单选 · `multi` 多选 · `truefalse` 判断 · `fill` 填空 · `explain` 名词解释 · `short` 简答 |
| `answer` | 选择/多选/判断：**0 起始下标数组**（多选如 `[0,2,4]`；判断题用 `answerText: ["true"]`） |
| `answerText` | 文本题参考答案数组；判断题 `["true"]` / `["false"]` |
| `options[].en` | 双语题库可填，UI 会以小字显示 |
| `explain` | 解析（支持换行） |

也兼容旧的两批评测站格式，构建脚本会归一化：
- v1：`{stem, options:["…"], answer:3, explain, topic, tags}`
- v2：`{stem_zh, stem_en, options:[{zh,en}], answer:[3], …}`

## 五、从一份「复习站 HTML」生成存档

```powershell
$env:PYTHONIOENCODING="utf-8"
& "C:\Users\29866\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" `
  "D:\学习资料\_复习站App\fuyan\tools\build_archive.py" all
```

脚本里 `SITES` 字典是「按站点配置」的，新增一门课只要加一项：

```python
"newcourse": {
    "src": r"D:\...\新的复习站.html",
    "out": "newcourse",            # 存档 id
    "title": "新课名",
    "subtitle": "副标题",
    "version": "1.0.0",
    "nav_sel": "//nav[@id='nav']", # 导航容器（XPath）
    "badge_sel": ".//span[contains(@class,'ic')]",
    "count_sel": ".//em[contains(@class,'qmeta')]",
    "sec_prefix": "sec-",          # 锚点 → section id 的规则
    "chrome": [ "//aside[...]", "//div[contains(@class,'topbar')]", ... ],  # 要删掉的外壳
    "drop_nav": ["quiz"],          # 题库区（改由软件刷题页承担）
    "theme": {...}, "accent": "#0f766e",
    "css_fix": "/* 去掉外壳后的修正 */",
}
```

它会：
1. 删外壳、删 `<script>`、给 `.sec` 补 `active`；
2. 把原站交互按钮改写成 `data-act`；
3. 从 `<script id="quiz-data">` / `#quizData` 读题库并归一化；
4. 写 `manifest.json` / `content.html` / `questions.json`。

生成后建议：
- 打开 `content.html` 直接看一眼排版（`file://` 就能开）；
- 在软件里点开该存档，走一遍导航 / 翻转 / 折叠 / 刷题。

## 六、手工造一个最小存档（不用复习站）

```
demo/
├─ manifest.json
├─ content.html   <section id="s1"><h1>第一课</h1><p>正文……</p></section>
└─ questions.json
```

manifest 里 `nav` 只写 `{"anchor":"s1","title":"第一课","sectionId":"s1"}`，就能导入使用了。

## 七、校验清单

- [ ] `manifest.schema` = `fuyan/archive@1`，`id` 合法且与目录名一致
- [ ] `nav[].sectionId` 在 content 里都存在
- [ ] `questions[].answer` 下标不超过选项数
- [ ] 没有 `<script>`、没有外部依赖（CDN 字体/图片会导致离线打不开）
- [ ] 用 `python tools/build_archive.py` 生成的，检查控制台没有「缺题库文件」
- [ ] 导入后：导航能跳、翻转/折叠能用、刷题能答、批注能存
