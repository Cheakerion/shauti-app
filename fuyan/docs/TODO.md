## 5. DeepSeek / AI

- [x] **AI 门禁**：没配 Key 时点 AI 会弹引导（说明 DeepSeek 官方没有扫码登录，只能填 Key），配好才解锁。
- [ ] **真正的「扫码登录即用」**：DeepSeek 没有公开 OAuth / 设备码 / 扫码授权，第三方 App 拿不到。
      想要「别人扫码就能用、按你的账号扣费」，必须自建后端：
      ① 用户体系（手机号/微信扫码登录）→ ② 你的服务端存 DeepSeek Key、做转发与限额 → ③ App 里把 `lib/ai.js` 的直连换成你的接口。
      这属于商用阶段的工作量（要服务器、要备案/隐私政策、要计费）。
- [ ] **联网搜索**：用户原话是「deepseek 的搜索 api」。现状：DeepSeek 官方 API 没有公开的独立搜索接口（只有 chat completions），所以现在是「模型知识 + 选中原文」。
      - 备选：① 接第三方搜索 API（Bing/Google/博查/Serper）把结果塞进 prompt；② 用支持联网的模型/平台（如 DeepSeek 网页版）跳转；③ 自建抓取（不建议）。
      - 需要用户拍板选哪个、以及是否愿意为搜索 API 另外付费。
- [ ] **提示词模板可编辑**：不同学科（内科/外科/影像）用不同回答风格。
- [ ] **上下文**：现在只带「存档名 + 小节名 + 选中文字」。可加「同章节前后文」「这道题的解析」。
- [ ] **费用统计**：累计 token / 估算费用，设置页显示（当前账号扣费，用户会关心）。
- [ ] **多轮改判**：让 AI 用「考点/易错/口诀」三种模式回答。
- [ ] **答案缓存**：同一个选区重复问不重复扣费。
