# 发布与分发（作者操作）

> 目标：**存档包和软件一起发在 GitHub**；夸克网盘只作为作者自己的「作者通道」；别人下载后不需要你的网盘、也不需要你的 Key。

---

## 零、放到别人的仓库（fork + PR）

如果目标仓库不是你自己的（比如好友的 `Cheakerion/shauti-app`），你没有 push 权限时：

```powershell
gh repo fork Cheakerion/shauti-app --clone=false          # fork 到自己账号
git clone https://github.com/<你>/shauti-app.git          # 或复用已有克隆
# 把 fuyan/ 放进仓库根目录，提交
git push https://github.com/<你>/shauti-app.git HEAD:master
gh pr create --repo Cheakerion/shauti-app --head <你>:master --base master
```

对方合并后，内容就在原仓库里；没合并之前，jsDelivr / raw / Release 都能先用你 fork 的地址（本项目当前就是这样跑的）。

## 一、三条通道各管什么

| 通道 | 谁用 | 干什么 | 需要的账号 |
|---|---|---|---|
| **GitHub**（主通道） | 所有用户 | 下载软件、下载存档包 | 不需要 |
| **夸克网盘**（作者通道） | 只有你 | 传存档、取回存档、手机预览 | 你的夸克授权 |
| **本地 zip / 链接** | 你 + 收到私发的人 | 定制存档、临时分发 | 不需要 |

软件里对应的入口：

- 存档库「＋ 导入存档包」→ 本地 zip
- 存档库「🔗 从链接导入」→ 任意 http(s) 直链（GitHub Release 资产、对象存储、分享直链都行）
- 存档库「☁ 网盘（作者通道）」→ 只有你这台机器能用（见第四节）
- 存档库「GitHub 在线存档」→ 读你在设置里填的 `archives.json`，点一下下载导入

## 二、GitHub 发布流程（推荐）

### 1. 建仓库

建议 `fuyan`（公开），里面放：

```
README.md
archives.json          # 在线存档清单（也可以放 release 资产里）
dist/                  # 可选：存档 zip（或者放 Release）
```

### 2. 生成清单和存档包

一条命令（先登录一次 `gh auth login`）：

```powershell
cd D:\学习资料\_复习站App\fuyan
.\tools\publish-github.ps1 -Repo makainuo/fuyan -Tag v0.1.0
```

它做四件事：打包软件 → 生成 `dist/archives.json` 与存档 zip → 建仓库/提交/推送 → 打 Release。
只想先生成文件、不联网：

```powershell
.\tools\publish-github.ps1 -Repo makainuo/fuyan -DryRun
```

产物：

```
dist/fuyan-v0.1.0.zip          # 软件（不含 data、不含截图，约 150KB）
dist/infectious-1.3.0.zip
dist/digestive-2.0.0.zip
dist/archives.json
```

`archives.json` 长这样：

```json
{
  "schema": "fuyan/catalog@1",
  "updatedAt": "2026-11-14",
  "archives": [{
    "id": "infectious",
    "title": "传染病学",
    "subtitle": "期末复习综合站",
    "version": "1.3.0",
    "notes": "22 名解 · 10 简答 · 14 病例 · 196 题",
    "size": 130721,
    "updatedAt": "2026-11-14",
    "url": "https://github.com/<你>/fuyan/releases/download/v0.1.0/infectious-1.3.0.zip"
  }]
}
```

### 3. 传 Release

- 新建 tag `v0.1.0`，把 `dist/*.zip` 传成 Release 资产；
- `archives.json` 可以直接提交到仓库（推荐），也可以一起传成资产。

### 4. 在软件里填两个地址

「设置」里：

| 字段 | 填什么 |
|---|---|
| **在线存档库** | `https://raw.githubusercontent.com/<你>/fuyan/main/archives.json` |
| **软件更新源**（后续做） | `https://raw.githubusercontent.com/<你>/fuyan/main/version.json` |

填完回存档库，就会出现「GitHub 在线存档」，点「下载导入」。

> 没有 raw 域名被墙的顾虑时也可以直接填 Release 里的 `archives.json` 地址；`fetchJSON` 支持任意 https 直链。

### 5. 国内网络怎么填（重要）

本机实测：`github.com` 与 `raw.githubusercontent.com` **超时**，`cdn.jsdelivr.net` 正常。软件已经优先走 jsDelivr，所以推荐这样填：

| 字段 | 填什么 |
|---|---|
| **软件更新 → GitHub 仓库** | `你的账号/fuyan`（会自动试 jsDelivr 的 `@main` / `@master`，再回落 raw） |
| **在线存档库** | `https://cdn.jsdelivr.net/gh/你的账号/fuyan@main/dist/archives.json` |

对应的存档包地址由 `make-catalog.mjs` 生成：

```powershell
node tools/make-catalog.mjs --repo 你的账号/fuyan
# 等价于 --base https://cdn.jsdelivr.net/gh/你的账号/fuyan@main/dist
```

这样 `dist/*.zip` 提交进仓库后，别人下载存档走 jsDelivr，不用访问 github.com。
> jsDelivr 单文件有 20MB 左右限制；本项目的存档包都在 150KB 内，没问题。

## 三、用户拿到的体验

1. 从 GitHub 下载 `fuyan-v0.1.0.zip`（解压即用，双击 `启动复研.bat`）；
2. 打开 → 存档库 → 「GitHub 在线存档」→ 点「下载导入」；
3. 阅读 / 刷题立即可用，不需要任何账号；
4. 想用 AI：点「问 AI」会弹引导，去 DeepSeek 开放平台建一个 Key 填进来（用他自己的账号扣费）。

## 四、网盘（作者通道）的规则
以后往 `dsh传输` 传存档，**同名文件顶替**：

1. 新的先传上去（网盘会自动命名成 `xxx(1).zip`）；
2. 旧的重名版本自动移进 `旧测试` 子目录；
3. 根目录永远只有最新版。

两种触发方式：

- **软件里**：存档卡片「⋯ → 发布到网盘（作者通道）」——自动完成「导出 → 上传 → 归档旧版」，并提示移动了几个旧包。
- **命令行**：`node tools/quark-cleanup.mjs --dry` 先看，去掉 `--dry` 执行（会把根目录所有文件移进 `旧测试`）。

⚠️ 夸克 CLI **没有删除命令**（官方说明里明确「删除文件不代做」）。所以要彻底删，只能在夸克 App / 网页里手动删 `旧测试` 文件夹。

⚠️ 网盘通道依赖本机 WSL + `quark-drive.cjs` + 你的夸克授权；**别人机器上没有这些**，所以这个入口对普通用户应当是不可用状态——这是设计如此。分发时不要把你的 `data/config.json` 一起打包（里面有你的网盘 fid）。

## 五、AI 授权说明（重要）

**DeepSeek 官方 API 没有「扫码登录」授权方式**，只有 API Key。所以：

- 软件做的是「**门禁 + 引导**」：没 Key 时 AI 功能会弹引导（说明 + 打开开放平台 + 去设置填 Key），填好并测试通过才解锁；
- Key 只存本机，服务端转发，前端拿不到；
- 想让「扫码就能用、按作者账号统一扣费」，必须自己搭后端（账号体系 + 计费 + 转发），现有代码留了扩展点（`lib/ai.js` 换成你的转发服务即可）。见 `docs/TODO.md`。
